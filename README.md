# Dowell DM10 / D10 + Klipper на Chitu V3.10

> Рабочая конфигурация Klipper для большого FDM-принтера **Dowell DM10 (D10) 1000×1000×1000** на стоковой материнской плате **Chitu V3.10 (STM32F103ZET6)**.

## Что внутри

| Файл | Описание |
|------|----------|
| `printer-chitu-v310-dowell-d10.cfg` | Полный конфиг Klipper (проверен на железе) |
| `Chitu_V3.10_pinout.md` | Распиновка платы с проверенными GPIO |

## Основные фичи конфига

- ✅ **3D Touch / BLTouch с автовыдвижением щупа** — сенсор на `PA14` (Z-), servo на `PG4` (ERROR)
- ✅ **Проверенная распиновка** всех концевиков, датчиков, вентиляторов
- ✅ **Bed Mesh** 7×7 для стола 1000×1000 мм
- ✅ **Input Shaper** (заглушки 50 Гц — требует калибровки)
- ✅ **Exclude Object** для Orca Slicer
- ✅ **Макросы** START_PRINT / END_PRINT / PAUSE / M600 / G29 / M48 и др.
- ✅ **Датчик филамента** на `PA15`

## Прошивка (кратко)

1. Соберите прошивку с параметрами:
   - MCU: STM32F103
   - Bootloader offset: **0x8008800**
   - Communication interface: USART1 (PA10/PA9)
2. Сгенерируйте `update.cbd`:
   ```bash
   ./scripts/update_chitu.py ./out/klipper.bin ./out/update.cbd
   ```
3. Залейте на SD-карту и прошейте через стоковый загрузчик Chitu.

Подробнее — в комментариях внутри `printer-chitu-v310-dowell-d10.cfg`.
